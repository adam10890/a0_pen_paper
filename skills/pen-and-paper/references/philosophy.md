# Philosophy: "Thinking in Writing"

## Core Principles

Pen & paper is not just a logging tool; it is a **sequential thinking mechanism** with persistence.

Agents often forget steps mid-task, lose track of items to backtrack on, or fail to learn from repeated mistakes. Pen & Paper forces structured thinking:

1. **Open workspace** → Commits you to a structured process.
2. **Record findings** → Ensures discoveries aren't forgotten.
3. **Document decisions** → Clarifies *why* a particular decision was made.
4. **Mark backtrack** → Guarantees important edge cases aren't missed.
5. **Close workspace** → Summarizes and integrates into the local knowledge base.

## Compared to Default Sequential Thinking

| Aspect | Default Sequential Thinking | Pen & Paper |
|---|---|---|
| **Storage** | In memory | Persistent files |
| **Structure** | Single thought string | Structured sections (findings, decisions) |
| **Concurrency** | Single thread | Multiple parallel workspaces |
| **Learning** | None | Integrates with Adaptations System |
| **History** | Ephemeral | Long-term |
